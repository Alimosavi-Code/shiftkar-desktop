# ShiftKar Neo — شیفت‌کار نئو (Desktop Edition v6.7.3) 🖥️

نسخهٔ دسکتاپ **شیفت‌کار نئو (v6.7.3)** هماهنگ با نسخهٔ اندروید و وب، ساخته‌شده با **Kotlin + Compose Multiplatform for Desktop** برای:
- 🐧 **Linux** (`.deb`, `.rpm`, `.AppImage`)
- 🍎 **macOS** (`.dmg`)
- 🪟 **Windows** (`.msi`, `.exe`)

---

## ✨ قابلیت‌های جدید در نسخهٔ دسکتاپ v6.7.3
- **هماهنگی ۱۰۰٪ با بیس اندروید و وب (v6.7.3)**:
  - پشتیبانی از **۴۵ الگوی استاندارد شیفت** + **سازندهٔ الگوی سفارشی** + پشتیبانی از شیفت **عصرکار** (و مخفی‌سازی هوشمند در الگوهای فاقد عصرکار) + پشتیبانی از ۱ تا ۸ گروه شیفتی (`A..H`).
  - **تب پنجم «مدیریت شیفت و پرسنل»**: ویرایشگر پاپ‌آپ الگو (`SkSheet`)، ثبت مرخصی/اضافه‌کاری/جابجایی پرسنل، و کارکرد فیش حقوقی.
  - **لوحهٔ کلاسیک ۱۶ ستونی (۱۲ ماهه بدون فروردین سال بعد)**، لوحهٔ رسمی سمَت‌ها، و ماتریس ۴ شیفت منطبق با آخرین تقویم رسمی **مرکز تقویم مؤسسهٔ ژئوفیزیک دانشگاه تهران**.
  - **نوار خلاصهٔ ماهانهٔ واکنش‌گرا (`MonthlySummaryStrip`)** و کارت‌های شیشه‌ای یادداشت (بدون پس‌زمینهٔ زرد قدیمی).
  - **خروجی تصویر باکیفیت (PNG)** برای تمام نماها + **کپی مستقیم تصویر در کلیپ‌بورد (`کپی در کلیپ‌بورد`)** و ذخیرهٔ فایل.
  - **پشتیبان‌گیری یکپارچه (`.json`)** سازگار بین اندروید، وب و دسکتاپ.
- **قابلیت‌های اختصاصی دسکتاپ و رفع باگ‌های ویندوز**:
  - **حذف نوار عنوان تکراری در ویندوز**: حفظ تنها نوار عنوان اصلی سیستم‌عامل با نمایش زندهٔ تاریخ و شیفت روز.
  - **منوی راست‌کلیک شیشه‌ای جدید کنار ساعت (System Tray)**: جایگزینی منوی قدیمی ویندوز (که حروف فارسی را به شکل علائم نامفهوم نشان می‌داد) با منوی شیشه‌ای Compose و فونت فارسی شفاف `IRANSansX` به‌همراه دسترسی سریع به بخش‌های برنامه + **آیکون زنده کنار ساعت** با نمایش عدد روز جاری.
  - **ویجت شناور رومیزی (`Desktop Floating Mini-Widget`)**: ویجت شیشه‌ای قابل جابجایی و سنجاق‌شدن روی دسکتاپ (`Ctrl+W`).
  - **رنگ دینامیک سیستم‌عامل (`Dynamic OS Accent Color`)**: خواندن خودکار رنگ تم ویندوز ۱۰/۱۱، macOS و لینوکس (KDE / GNOME).
  - **نوار پایین با بلور شیشه‌ای مشابه PWA**: افکت بلور شیشه‌ای شفاف (`FrostBarBackdrop`) در نوار ناوبری پایین.

## 💻 ۱. روش اجرا و ساخت روی سیستم خودتان (Local Build)

### پیش‌نیازها:
- نصب بودن **JDK 17** یا بالاتر (پیشنهاد: Eclipse Temurin 17).

### دستورات ترمینال:

```bash
# ۱. اجرای مستقیم و زنده برنامه روی دسکتاپ:
./gradlew :composeApp:run

# ۲. اجرای برنامه به صورت مستقل (Unpackaged binary):
./gradlew :composeApp:runDistributable

# ۳. ساخت فایل نصاب برای سیستم‌عامل فعلی شما:
./gradlew :composeApp:packageDistributionForCurrentOS
```

---

## ☁️ ۲. ساخت خودکار هر ۳ سیستم‌عامل با GitHub Actions

فایل گردش‌کار آماده در مسیر `.github/workflows/build-desktop.yml` قرار دارد و با هر Push روی شاخهٔ `main`، نصاب‌های ویندوز (`.exe` / `.msi` / `.zip`)، مک (`.dmg`) و لینوکس (`.deb` / `.rpm` / `.AppImage`) را به همراه هش امنیتی `SHA-256` می‌سازد.
